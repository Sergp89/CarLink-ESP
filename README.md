## 📖 О проекте

**CarLink ESP** — это мобильное приложение-компаньон для автомобильной телематической системы на базе ESP32-S3 (Phase 1) и ESP32-P4 (Phase 2).

Приложение обеспечивает:
- 📊 **Мониторинг в реальном времени**: скорость, обороты, температура, давление
- 🛰️ **GPS-трекинг**: местоположение, маршрут, история поездок
- ⚠️ **Уведомления**: тревоги по газу, перегреву, превышению скорости
- 📈 **Аналитика**: графики, статистика, экспорт логов
- ⚙️ **Настройки**: конфигурация системы без перепрошивки
- ☁️ **Облако**: синхронизация данных с сервером (опционально)

## 🎯 Возможности

### Phase 1 (ESP32-S3)
- [x] Подключение по Wi-Fi / Bluetooth
- [x] Отображение данных CAN-шины (OBD-II)
- [x] Мониторинг датчиков (температура, влажность, газ, давление)
- [x] GPS-трекинг и карта маршрута
- [x] Просмотр и экспорт логов с SD-карты
- [x] Настройка порогов тревог
- [x] Уведомления о критических событиях

### Phase 2 (ESP32-P4)
- [ ] Потоковое видео с камеры
- [ ] Голосовые команды и уведомления
- [ ] Распознавание усталости водителя (AI)
- [ ] Интеграция с облачными сервисами (погода, карты)
- [ ] OTA-обновление прошивки ESP32
- [ ] Мульти-автомобиль (гараж)

## 🔧 Технические требования

| Компонент | Требование |
|-----------|------------|
| **Android** | 8.0+ (API 26) |
| **ESP32** | ESP32-S3 N16R8 / ESP32-P4 |
| **Связь** | Wi-Fi 2.4GHz / Bluetooth LE |
| **Протокол** | MQTT / HTTP REST / WebSocket |
| **База данных** | Room (локально) + SQLite |
